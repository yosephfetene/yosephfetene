I'm a 3rd year Computer Science student who cares about how software solves real problems at scale. My work sits where AI engineering, backend systems, and low level performance meet.

- Building secure backend APIs in **Rust**, with a focus on memory safety and performance
- Shipping **RAG systems**: vector embeddings, semantic search, and ingestion pipelines over messy real world data

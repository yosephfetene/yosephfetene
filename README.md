### About

I build backend services and low-level systems, and I spend my days debugging other people's integrations as a support engineer, which is its own kind of education. Most of my side work is reimplementing things from first principles to find out how they actually work.

- 🔭 Currently building **PeerNest**, a BitTorrent client in Node.js
- 🧱 Recently shipped **ImmuStore DB**, a key-value storage engine with an immutable tree index
- 🌱 Working through a structured AI/ML roadmap
- 💬 Ask me about storage internals, distributed protocols, or Firebase gotchas
- 📍 Based in Vancouver, Canada
